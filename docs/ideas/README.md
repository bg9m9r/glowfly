# Ideas

Polish, edge cases and power-user extras that are not planned work. Each line is one untriaged
idea, kept under the heading of the feature it grew from. Nothing here is built until it is
promoted.

- **Adding an idea**: a follow-up, polish item or edge case found while building goes here as a
  one-line bullet under the matching heading in the right file (add the heading if it is new).
  A substantial new feature is an issue instead.
- **Promoting an idea**: open a GitHub issue for it (it lands in the Project's Inbox for
  triage) and remove the line here in the same change. Several related lines can become one
  issue.
- **Dropping an idea**: delete the line; git history keeps it.

Planned work is tracked as [issues](https://github.com/bg9m9r/glowfly/issues) on the Glowfly
Project; see [ROADMAP.md](../../ROADMAP.md) for the milestones.
